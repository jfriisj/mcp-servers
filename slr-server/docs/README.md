## 📝 Contributing to Documentation

When adding new documentation:

1. **Create the file** in this directory or appropriate subdirectory
2. **Follow naming** - Use descriptive names with hyphens (e.g., `my-feature.md`)
3. **Use Markdown** - Follow existing formatting and style
4. **Add to index** - Update this README with link and description
5. **Link from related** - Add cross-references to related documents
6. **Keep focused** - Each document should have a clear purpose

### Documentation Standards
- Use clear headings and structure
- Include code examples where relevant
- Add tables for reference information
- Use consistent formatting
- Link to related documents
- Keep technical content accurate
