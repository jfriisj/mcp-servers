## QUALITY CONTROL MEASURES

### Real-Time Quality Checks
1. **Relevance Spot Check**: Review every 20th result for relevance
2. **Coverage Validation**: Ensure known important papers are captured
3. **Duplicate Monitoring**: Track duplicate rates across databases
4. **Search String Effectiveness**: Monitor hit rates and relevance

### End-of-Day Reviews
1. **Results Distribution**: Check balance across years, venues, approaches
2. **Gap Analysis**: Identify missing expected literature
3. **Strategy Adjustment**: Modify searches based on findings
4. **Documentation Check**: Ensure all searches properly recorded

### Weekly Quality Meetings
1. **Coverage Assessment**: Review overall literature coverage
2. **Search Strategy Refinement**: Update approaches based on results
3. **Inter-database Comparison**: Analyze overlap and unique contributions
4. **Timeline Adjustment**: Modify plan if needed

## TROUBLESHOOTING GUIDE

### Too Few Results (<50 total)
**Actions:**
1. Broaden search terms (remove "real-time" constraint)
2. Include related terms ("simultaneous interpretation")
3. Extend date range to 2010-2025
4. Search for "speech translation" + add filters later

### Too Many Results (>1000 total)
**Actions:**
1. Add more specific architectural terms
2. Focus on peer-reviewed venues only
3. Limit to recent years (2020-2025) initially
4. Require multiple key terms in title/abstract

### Low Relevance Rate (<30%)
**Actions:**
1. Add more specific technical terms
2. Use database subject classifications
3. Focus on known high-quality venues
4. Refine Boolean combinations

### Database Access Issues
**Actions:**
1. Contact library for access support
2. Use institutional VPN if off-campus
3. Try alternative databases with similar coverage
4. Document access issues for reporting
