## Next Steps: Obtaining Full Text

To proceed with full-text screening, you will need to:

### Option 1: Retrieve from Original Sources
1. **IWSLT Papers**: Download from [IWSLT Conference Website](https://iwslt.org)
   - Proceedings available: 2021, 2022, 2023, 2024, 2025
   
2. **arXiv Papers**: Check arXiv for preprints
   - Format: arXiv.org/abs/XXXX.XXXXX
   
3. **Publisher Databases**:
   - ACL Anthology (for ACL, INTERSPEECH, ICASSP papers)
   - IEEE Xplore (for IEEE conference papers)
   - Springer Link (for conference proceedings)
   - Conference websites directly

### Option 2: Automated Retrieval
Use tools to batch download papers:
- **Scihub** (controversial but effective for research)
- **CORE** API (academic aggregator)
- **Semantic Scholar** API
- **UNPAYWALL** API (legal OA paper finder)

### Option 3: Institutional Access
If working from an academic institution:
- Use your university library database access
- Request through interlibrary loan (ILL)
- Contact authors directly for preprints
